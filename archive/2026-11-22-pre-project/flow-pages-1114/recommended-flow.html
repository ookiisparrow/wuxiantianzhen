推荐方案流程

官方电子面单 + 取号时预约上门 + 手机蓝牙打印。每一步都在抖店官方规则和接口范围内,全程不解密、不存买家明文。快递选顺丰,原因见图下。

有官方依据 未证实,待确认

为什么选这个方案

规则或限制这个方案怎么满足
平台要求用官方电子面单面单由抖店取号,不使用外部单号,不落入自行寄件额度和虚假发货的风险。
买家信息不落库只保存密文,不调用解密接口,不占用解密率和额度,不用部署在抖店云(机器人回复)。
面单和订单收件信息一致每次用该订单自己的最新密文取号,买家改地址后重新取。
寄件地址须是已登记的织女入驻时先登记,取号时只传这些地址。
蓝牙打印要在支持范围内官方 FAQ 的蓝牙支持名单:顺丰、中通、圆通、极兔、韵达、邮政、申通。**京东不在内**。

为什么选顺丰,不选京东

  • 顺丰和京东都是直营型:凭月结账号开通,手机号验证,织女地址登记方式相同。
  • 顺丰在蓝牙打印支持名单里,京东不在。机器人还称顺丰支持取号时的取件时间段(未证实)。
  • 你们现有的是京东月结号,这个方案用不上它,需要向顺丰另行签约月结账号。以后若要回到京东,要先解决京东面单的蓝牙打印(京东云打印,未验证)。

这个方案还有四处没证实

  1. 个体工商户办软著时,著作权人怎么填(平台页面没写)。
  2. 取号时的 sender_fetch_time 对顺丰真的会预约上门。
  3. 蓝牙打印机型号:已有部分清单(图片),要对着拖店 App 核对。
  4. 自动发货对 API 取号生效。
