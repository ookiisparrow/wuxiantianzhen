# 调研任务：抖店 + 快递100 链路可行性

> 给 Claude Code 的任务说明。请先读完再动手。

## 1. 背景（只保留与本任务有关的）

- 项目：织女（钩织手艺人）预售平台，唯一交易场所是微信小程序，技术栈 uni-app + 微信云开发（CloudBase）。主体是个体户。
- 订单规则要点：买家付款后 12 小时确认期；之后按整点派单给分散在各地的织女（每次最多 3 单、1 小时内回复）；织女接单即开始制作，14 天内寄出；接单后买家取消，20% 定金归织女；织女看不到买家个人信息。
- 现在想验证的链路：**直播间挂抖店商品 → 买家在抖店下单 → 订单拉进我们的小程序后台 → 派给织女 → 织女在小程序里预约快递上门取件（用快递100接口）→ 运单号回传抖店**。
- 已有的判断：这条链路里，分发这一段在我们自己系统内，没有问题。风险全在抖店和快递100两侧。

## 3. 已经核实过的事实（不用重查，但请在发现矛盾时指出）

快递100官方文档（均来自 api.kuaidi100.com）：

- 订单导入接口（`/document/61b937f4484d725c7e745d85`）支持抖店（店铺类型 TOUTIAO）：店铺授权超链接、按更新时间范围拉取订单（异步任务 + 回调）、售后订单接口（仅淘宝、抖店）、快递单号回传并发货。页面警告：订单号/快递公司编码/单号填错会被电商平台风控拦截。订单字段同时有明文和密文（Enc 结尾）两套，**没有说明抖店订单返回哪一种**。
- 订单导入产品页（`/document/dingdandaoruchanpinjieshao`）：抖店需先在抖店服务市场购买“快递管家”，调试可用 7 天试用；预充值，按订单获取的时间区间按分钟计费。
- 电子面单接口（`/document/dianzimiandanV2`）：`net=douyin` 表示使用抖音授权；此时返回 PDF，`printType` 不起作用；通过第三方授权取号要先用授权接口（`https://poll.kuaidi100.com/printapi/authThird.do`）拿 `partnerId`/`partnerKey`，仅主账号可授权。
- 电子面单授权文档（`/document/5fc769198277665dce5373b3`）：授权接口流程（返回 200 已授权；201 返回授权链接）、回调内容。
- 上门取件（线上支付）（`/document/5f0ff095bc8da837cbd8aef6`）：预充值预扣运费，余额须大于最后一单运费；仅支持寄付；取件时间窗至少 1 小时；回调状态含已接单、已取件、派送中、已签收、已结算，失败重试 3 次、间隔 30 分钟；支持取消（当月订单最晚次月 8 日前）；面单返回方式 `returnType` 10 设备打印、20 图片短链。
- 上门取件（线下支付）（`/document/cduan-ji-jian-jie-kou-wen-dang`）：运单号一般下单即返回，中通、圆通、顺心捷达需等“已取件”回调；有取消接口；状态码含 11 揽货失败。
- 优选快递（`/document/5f0ff0a5bc8da837cbd8aef7.html`）：有运力查询接口（按寄件地址返回覆盖的快递公司，201 表示无运力），回调含快递员姓名电话、重量、运费。
