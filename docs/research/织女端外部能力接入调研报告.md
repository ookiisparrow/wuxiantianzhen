## 1. 核心结论与 4 项必须提前避开的硬坑

**结论**：v5 织女筛选与开单全流程涉及的 8 类外部能力，**个体工商户主体全部有合规可落地的接入路径**，但存在 4 个会直接卡住上线节奏或引发返工的硬约束：

1. **最耗时的两项前置审核必须立刻并行启动**：
   - **微信小程序 ICP 备案**：微信初审 1–2 个工作日 + 工信部 24 小时短信核验 + 省管局终审（通常 **3–7 个工作日**，法定上限 20 个工作日）。
   - **腾讯云短信运营商实名报备**：腾讯云平台审签名约 2 小时，但随后自动提交三大运营商实名报备，观测周期 **7–10 个工作日**（且报备后闲置 7 天–3 个月会被运营商回收失效，需保持低频心跳发送）。
2. **微信支付「商家转账到零钱」（`transfer-bills`）个体户无法开通**：
   - 微信支付自 2025-01-15 上线新版商家转账（`/v3/fund-app/mch-transfer/transfer-bills`），**仅对企业主体开放，个体工商户不可申请**。
   - **落地对策**：200 元保证金支付后 **365 天内**退出走微信支付 V3 **原路退款**（个体户可用，零手续费退还规则按商户协议）；超过 365 天退还及 14 天批量结款，个体户阶段走**银行卡打款 / 网银批量代发**（用已实名绑定的身份信息核对），阶段 2 迁有限公司后再启用 `transfer-bills`。
3. **微信隐私指引与类目强拦截**：
   - 必须在小程序后台填写《小程序用户隐私保护指引》，**逐项勾选**手机号、模糊地理位置、相册/相机、收货地址；漏填一项对应 API 在真机上直接禁用。
   - `wx.getFuzzyLocation` 仅对「地理位置强相关类目」开放，且代码提审环节会自动拦截未开通权限的小程序；**若工具类目被拒，直接降级由 `wx.chooseAddress`（免审批）或腾讯 IP 定位兜底**。
   - `getPhoneNumber` 仅对**非个人主体且完成微信认证**的小程序开放，且必须由用户**亲手点击** `<button open-type="getPhoneNumber">` 触发（无法在 `wx.login` 回调里自动弹）。
4. **6 位织女码与代码端口补充**：
   - 手机号后 4 位在 100 单在途包裹时撞号率达 39.4%，改为**后台生成唯一 6 位数字织女码**（100 万空间，如 `609205`，建稀疏唯一索引 `users.weaverCode`），同时用于寄样包裹纸条识别与转正工号展示。
   - 现有 [ports/index.ts](file:///Users/sparrow/wuxiantianzhen/packages/cloud/src/ports/index.ts) 已具备 `PaymentPort`、`LogisticsPort`、`NotificationPort`、`ContentSecurityPort`，正式对接前需新增 3 个端口：`WeChatIdentityPort`（登录与手机号换取）、`GeoPort`（逆地理编码）、`IdentityVerifyPort`（身份证 OCR + 二要素核验）。

## 2. 八大外部能力官方接入明细

### 2.1 微信登录 + 隐私协议授权

| 维度 | 官方规范与接入细节 |
|---|---|
| **前端 API** | `wx.login()` + `wx.getPrivacySetting()` / `wx.requirePrivacyAuthorize()`（或 `<button open-type="agreePrivacyAuthorization">`） |

### 2.2 微信一键获取手机号

| 维度 | 官方规范与接入细节 |
|---|---|
| **前端组件** | `<button open-type="getPhoneNumber" bindgetphonenumber="onGetPhone">`（建议直接作为首页唯一绿色主按钮，点击一次触发授权） |
| **服务端 API** | `POST https://api.weixin.qq.com/wxa/business/getuserphonenumber?access_token=ACCESS_TOKEN`（传入回调的 `e.detail.code`，有效期 **5 分钟**、单次消费，**勿与 `wx.login` 的 `code` 混用**） |
| **主体要求** | 非个人主体（**个体工商户可开**），但**必须先完成微信认证**（个体户微信认证年费 30 元） |
| **官方定价** | **快速验证组件 0.03 元/次**（实时验证 0.04 元/次）；每个小程序送 **1,000 次免费体验额度**（开发/体验/正式版共用），仅在 `bindgetphonenumber` 回调 `success` 时扣费；可配 `phone-number-no-quota-toast="false"` 自定义欠费降级手输手机号 |
| **避坑点** | 微信严禁“未看任何内容直接强制弹窗要手机号”；首页先完整展示平台简介与核心承诺，用户主动点击「微信一键授权并开始」按钮才拉起手机号授权，完全符合《微信小程序平台运营管理规范》。 |

### 2.3 自动位置识别 + 逆地理编码 + 地址簿兜底

| 维度 | 官方规范与接入细节 |
|---|---|
| **主路径前端 API** | `wx.getFuzzyLocation({ type: 'gcj02' })`（返回粗略经纬度，需在 `app.json` 声明 `requiredPrivateInfos: ["getFuzzyLocation"]` 与 `permission["scope.userFuzzyLocation"]`） |
| **经纬度转省市区** | **腾讯位置服务 WebService 逆地址解析**：`GET https://apis.map.qq.com/ws/geocoder/v1/?location=lat,lng&key=KEY`（云函数后端调用，防 Key 泄露；个人/企业开发者均有免费日配额，百万级以内几乎零成本） |
| **兜底前端 API** | `wx.chooseAddress()`（拉起微信原生收货地址簿，**无需额外接口审批**，仅需在隐私指引中声明“收货地址”；**同时也是寄样上门取件获取精确门牌号的必需步骤**） |
| **开通与审核** | `wx.getFuzzyLocation` 需在「微信公众平台 → 开发管理 → 接口设置」自助提交申请（附带页面截图与场景说明，约 1 个工作日审核）。若 `mp-weaver` 所选工具类目未批，可无痛降级为“服务端 IP 定位 + `wx.chooseAddress` 一键确认”。 |

### 2.4 拍照上传与 UGC 图片内容安全

| 维度 | 官方规范与接入细节 |
|---|---|
| **前端 API** | `wx.chooseMedia({ count: 1, mediaType: ['image'], sourceType: ['camera'] })`（防盗图日期纸条实拍 & 身份证拍摄锁死仅 `['camera']`；接单截图/旧作允许 `['album', 'camera']`）；前端用 `wx.compressImage` 压至 ≤500KB 再上传微信云存储 |
| **服务端 API** | **微信多媒体内容安全 2.0**：`POST https://api.weixin.qq.com/wxa/media_check_async?access_token=ACCESS_TOKEN`（Body 必传 `media_url`、`media_type: 2`、`version: 2`、`scene: 1~4`、`openid`） |
| **限制与费用** | **完全免费**；限额 **2,000 次/分钟、200,000 次/天**，单图 ≤10MB |
| **关键避坑点** | 1. 传入的 `openid` 必须是**近 2 小时内访问过小程序**的用户，否则报错。<br>2. 结果为**异步回调推送**（通过微信消息推送 URL 返回 `TraceId` + `suggest: pass/risky/review`），必须保留状态机拦截 `risky` 图片，对应已有 [ports/index.ts](file:///Users/sparrow/wuxiantianzhen/packages/cloud/src/ports/index.ts#L57-L66) `ContentSecurityPort`。 |

### 2.5 快递100 API（预约上门取件 + 物流回调 + 扫码兜底）

快递100 开放平台（`https://api.kuaidi100.com`）对我们有两个**完美互补**的官方接口，分别匹配「考题寄样」与「正式发货」：

| 业务场景 | 推荐产品与官方接口 | 运费结算方式 | 接口调用费与运费参考 |
|---|---|---|---|
| **考题寄样（织女自费寄回质检仓）** | **上门取件 API（线下支付）**<br>`POST https://order.kuaidi100.com/order/corderapi.do`<br>`method=cOrder` | **寄件人（织女）线下当面付给快递员**<br>平台**零垫资、零预充、零财务对账** | **圆通、京东、德邦等免收接口调用费**（且圆通、德邦享专属折扣运费）；仅顺丰/中通/EMS 需购次数套餐（下单成功才计费） |
| **正式接单发货（织女寄给买家）** | **上门取件 API（线上支付）**<br>`POST https://poll.kuaidi100.com/order/borderapi.do`<br>`method=bOrder` | **平台在快递100企业后台预充值，快递员揽收后实时预扣，次月统一对账** | **接口调用完全免费**；官方折扣低至 3 元/单起，热门跨省线路约 **5.6 元起**；支持**智选运力**（5 分钟无人接单或超预约时间自动调度兜底运力 + 丢破损协助理赔） |
| **极速上线备选** | **免开发寄件组件** (`apiSdk`) | 支持“寄件人现付”或“平台预充”，并支持**锁死收件仓地址** | 商务确认组件费率；免自绘前端寄件表单 |
| **村镇不上门兜底** | 微信原生 `wx.scanCode({ scanType: ['barCode'] })` + 快递100 订阅推送 (`poll`) | 织女驿站自寄，扫码登记运单号 | 微信扫码免费；快递100 轨迹推送按单计费 |

**统一加签与回调规范**：
- 签名：`sign = MD5(param + t + key + secret).toUpperCase()`（`t` 为 13 位毫秒时间戳）。
- 回调 `callBackUrl`：需公网可访问 URL（≤200 字节），接单(`1`) / 已取件(`10`) / 揽收失败(`11`) / 取消(`99`) 主动 POST 推送运单号 `kuaidinum`、快递员信息、重量与运费；服务端验签后返回 `{"result": true, "returnCode": 200, "message": "成功"}`，直接对接 [ports/index.ts](file:///Users/sparrow/wuxiantianzhen/packages/cloud/src/ports/index.ts#L29-L40) `LogisticsPort` 与 `webhook-kuaidi100`。
- **隐私面单与剩余确认项**：注册企业账号时可用个体户营业执照；关于个体户实审时长、HTTPS 回调直连云函数、住宅/村镇覆盖与隐私面单字段，可直接发出仓库内已写好的 [kuaidi100-business-questions.md](file:///Users/sparrow/wuxiantianzhen/docs/research/outbound/kuaidi100-business-questions.md)。

## 4. 建议推进顺序（按审核耗时倒排）

1. **第 1 天（立刻并行提交长耗时审批）**：
   - 注册 `mp-weaver` 与 `mp-buyer` 小程序（个体户营业执照）→ 提交**微信认证**与**小程序 ICP 备案**（3–7 工作日）。
   - 用同一营业执照申请**微信支付普通商户号**（1–3 工作日）+ 完成**腾讯云企业/个体户实名认证**。
   - 发送 [kuaidi100-business-questions.md](file:///Users/sparrow/wuxiantianzhen/docs/research/outbound/kuaidi100-business-questions.md) 给快递100商务（`api@kuaidi100.com`），申请测试账号并确认个体户开通 `cOrder` + `bOrder`。
2. **第 3–5 天（备案期间并行落代码接口）**：
   - 在 [packages/cloud/src/ports/index.ts](file:///Users/sparrow/wuxiantianzhen/packages/cloud/src/ports/index.ts) 补齐 `WeChatIdentityPort`、`GeoPort`、`IdentityVerifyPort` 端口定义与 `users.weaverCode`（6 位唯一码生成器），编写真实 HTTP Adapter（本地可用单元测试与 Mock 验证加签、幂等和验签）。
3. **第 7–10 天（小程序过审上架后收尾）**：
   - 后台开通 `wx.getFuzzyLocation`、配置《小程序用户隐私保护指引》、添加订阅消息模板 ID。
   - 小程序一上线立即提交**腾讯云短信实名资质 + 小程序签名**（抢跑 7–10 工作日运营商报备窗口）。
