# 抖店工单：开放平台开发者资格与电子面单（草稿，未发送）

提交位置：抖店开放平台客服或抖店商家后台帮助中心，提交工单（技术对接、开发者资质、电子面单）。正文不写姓名、手机号、详细地址。

## 背景
本店为个体工商户店铺，销售手工钩织商品。我们自建订单分发系统，需要用开放平台接口接收订单并通过电子面单发货，货由分散在各地的手工制作者从自家发出。想确认资格与限制后再投入开发。

## 问题
1. **个体工商户能否注册开放平台开发者，并申请“商家后台系统”类目的自用型应用？** 入驻标准写“企业”，FAQ 写“只支持公司主体”，个体工商户是否算“企业”？如果不行，有哪些替代路径？
2. **软著是必须的吗？** 软著证书、开发者主体、店铺主体三者必须一致，个体户自用型应用有无替代材料？审核大约多久？
3. **发货地址库一家店铺最多 500 个**：这个上限是否同样限制电子面单 API（`/address/create`、`/logistics/listShopNetsite`、`/logistics/newCreateOrder` 里的发货地址）？同一主体名下多个店铺是否各有 500？
4. **个人住宅地址**能否作为发货地址并用于电子面单 API 取号？不同快递（中通、圆通、韵达、申通、极兔、顺丰、京东）有无差异？电子面单账号与月结的要求是什么？
5. **在线寄件 API** 目前“已暂停，不支持新增对接”：是否有申请渠道、预计恢复时间？
6. **订单解密**：自用型应用如果只使用密文订单和省市信息、不调用解密接口，是否也必须部署在抖店云内？
7. **站外引流**：从抖音直播间或商品，引导买家到商家自有的微信小程序下单，是否被允许？相关规则出处是什么？（我们更关心老玩家复购与私域）
8. 自用型应用能否同时授权一个以上店铺？是否限制店铺与应用的主体一致？

## 答复后怎么用
- 个体户可做开发者：不用注册公司，软著按个体户办；
- 不可：立即注册公司，新店铺与应用都放公司下；
- 500 上限适用 API：直播池以 500 为容量，与设计一致；
- 站外引流被禁：小程序池的订单入口改为社群与老玩家私域，不从直播间导流。
