# 抖店工单（可直接提交）：在线寄件 多地址使用

提交位置：抖店商家后台，帮助中心，提交工单（物流发货，在线寄件）。正文不写姓名、手机号、详细地址。
工单正文有字数限制时，先提交"工单正文"，其余问题放在追问里。

## 工单标题
在线寄件：多个发货地址的使用上限、个人住宅地址、批量筛选订单，以及接口开放情况咨询

## 工单正文

您好，我们是抖店商家，店铺通过直播销售手工钩织商品。商品由分散在不同城市的手作人在各自家中制作，需要从手作人所在地直接发给买家。

我们计划用在线寄件：运营人员在抖店 PC 端「订单发货、发货中心、在线寄件」，每天按手作人分批勾选订单，把发货地址切换成对应手作人的地址，点"寄件并发货"。

我们看到学习中心写明"如果有多个发货地址，可直接在寄件时修改或新建"，也看到开放平台常见问题写明"在线寄件功能的 API 方案已暂停，不支持新增对接"。为确认这个用法能否成立，请逐条答复：

**一、发货地址（最关键）**
1. 开放平台智能客服答复一家店铺地址库最多 500 个发货地址，请确认在线寄件使用的就是这个地址库、上限同为 500。
2. 发货地址可以是个人住宅地址吗？寄件人姓名、手机号可以填手作人本人，与店铺主体不一致是否允许？
3. 新建发货地址是否需要审核？大约多久生效？
4. 发起寄件时，发货地址是否可以随时切换，不影响订单发货和售后校验？

**二、批量操作**
5. 「待寄件」列表能否按订单号批量筛选（一次粘贴多个订单号）？能否按商家备注或订单标签筛选？
6. 一次发起寄件最多能勾选多少个订单？

**三、面单**
7. 点击"寄件并发货"后，纸质面单由谁提供：快递员上门时自带，还是需要商家自己打印？如需打印，抖店 App 或手机蓝牙热敏打印机是否支持？

**四、开通范围**
8. 能否提供"在线寄件服务开通城市和物流商"的完整名单？个人住宅、小区、县乡、农村地址是否支持上门揽收？不支持时系统如何提示？

**五、接口**
9. 开放平台智能客服答复暂不支持任何途径申请，请问是否属实，预计何时恢复？
10. 第三方打单软件"快递管家"是否已支持在线寄件？

**六、使用限制**
11. 日均单量较低的新开店铺，在线寄件的价格和可用性有没有限制？
12. "当日 17 点前发起可当日上门"是否适用于所有已开通城市？

我们最想先得到第 2、7 条的答复，其次是第 5、9 条。谢谢。

## 追问备用（正文被拒或答复不全时再用）
- 子账号：能否给手作人开通抖店子账号，只开放"在线寄件"且只能看到分配给自己的订单？权限能否限制到订单级别？
- 收件信息：订单收件人信息是密文时，快递员如何获得收件地址？手作人作为寄件人能否看到买家收件地址？
- 电子面单取号接口 `/logistics/newCreateOrder` 的 `sender_fetch_time` 对哪些快递公司有效？取号后是否会通知网点派快递员？
- 费用：个人地址、偏远地区是否加价？预扣费规则？

## 拿到答复后怎么用
| 问题 | 答复是 | 方案怎么走 |
|---|---|---|
| 1、2 | 能建 100 个以上，可个人住宅 | 第一期按"运营每天批量在线寄件"推进 |
| 1、2 | 数量少或不允许个人地址 | 改用电子面单取号加织女打印，或把寄件收拢到少量集货点 |
| 7 | 快递员自带面单 | 织女不需要打印机 |
| 7 | 需要商家打印 | 确认手机蓝牙打印机方案，再决定要不要采购 |
| 9 | 有申请途径 | 走开发者认证加软著，做织女一键发货 |
| 9 | 没有 | 保持运营手动批量，小程序只做完成通知 |
