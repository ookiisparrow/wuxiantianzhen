# 法律咨询事项

## 一、业务情况

我们销售手工钩织的摆件、挂件，形象和图解均为自有。我们不自建工厂：各地的手工制作者（下称“织女”）在自己家中，按我们提供的图解制作，成品由织女直接寄给买家。我们负责接单、派单、提供图解、供应线材、审核成品照片、结款和售后。织女看不到买家信息。

**两条订单线**

- **抖音店铺**：约 500 位织女。买家付款给抖店，抖店结算给我们的店铺；店铺向织女支付加工费。
- **微信小程序**：织女人数不设上限。买家用微信支付付给我们的商户号，我们是卖方，织女受托加工，我们向织女支付加工费。

```
抖音店铺：买家 → 抖店 → 我们的店铺 → 加工费 → 织女
小程序：  买家 → 微信支付 → 我们的商户号 → 加工费 → 织女
```

**织女的工作方式**

- 自愿接单，可随时停止接单，拒单不受处罚；
- 系统按规则派单，织女 1 小时内确认；
- 每单交期 14 天，超期有记录，连续超期暂停派单；
- 工价按款式固定，每 14 天结算一次；
- 织女自备 12 种基础色线材，补充色号向我们申领，由指定供应商直接寄给织女，我们按个人额度记账；
- 须按我们的图解制作，成品拍照经审核后才能封袋寄出。
