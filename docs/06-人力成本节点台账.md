# 06 人力成本节点台账

> 用途：记录项目里所有需要人力投入的节点，并标出可以自动化的节点；用户自己决定谁来做、投入多少，我不推荐人力方案。
> 依据：用户 2026-11-22（第 6 轮）："仅把需要付出人力成本的节点记录好即可，如果有节点可以被自动化，那么要及时发现并告诉我。"
> 标记：人力量级（高/中/低）是我的估计，**未经实测**；"随规模增长"指随织女数或订单量线性增长。

## 2. 我认为最该优先自动化的 4 个节点

1. **#2 直播池在线寄件**：随织女数增长，规模到几百位时手工不可持续；这是 API 路径（订单 + 电子面单）的核心理由，而它依赖开发者资格（工单待答复）。
2. **#7 与 #8 织女准入漏斗**：你选了完整漏斗并要求不放松，每位新织女的作品审、试做审、样品验收都是人工节点，随织女数线性增长。能自动化的是小测验评分和视觉 AI 初筛；样品验收可以考虑交给志愿者。需要你在漏斗设计时决定自动化到什么程度。
3. **#5 成品照审核**：随订单量增长，已有信用分抽检、志愿者与图像指纹查重三个候选。
4. **#12 结款与 #18 对账**：规则明确、重复性强，最适合自动化；但涉及真实资金，需要会计确认口径。
