# 无限天真 / 织女平台

## 约定
- 术语：**款号**（`skuCode`，抖店商家编码，款级）；**袋码**（`bagQrCode`，封袋贴纸二维码，订单包级）。不使用"件码"。
- 金额全链整数分（`Fen`）；账本不可变；状态流转只走 `transition()`。
- 调研只信官方来源，标 `文档明确/文档没写/推断/实测`；不创建账号、不充值、不下真实订单、不自买刷单。
- 遇到与 `archive/` 不一致处，以 `docs/03-项目设计.md` 为准。
- 开发已启动（第 1 步 `@wxtz/*` Monorepo 底座、`shared` 契约与 `cloud` 核心引擎 + 单元测试已落地，运行 `npm run verify` 验证）；git 历史里的旧原型已隔离在本地 `legacy-prototype-2026-10` 分支，不属于新仓范围。
